Exchange 2019 Claude MCP

An open-source Model Context Protocol server, for developers and IT teams, that connects Claude to a self-hosted Exchange 2019 server (EWS) and Active Directory. Book meeting rooms, check colleagues' free/busy, manage calendar events and handle email in plain language, in English or Persian.

Built for production

Two-step booking

Claude shows a preview first. Nothing is booked until the user confirms, and free/busy is checked again on confirm.

Room verification

After booking, the server checks that the room accepted the meeting, and rolls the booking back if it declined.

Your own identity provider

Authentication is handled by your organization's OpenID Connect provider (tested with Keycloak), never by this server.

Room access control

Restrict rooms to Active Directory groups, including nested groups. The check fails closed.

Recurring meetings

Daily, weekly and monthly series, with availability checked for every occurrence.

Configurable

All organization data lives in .env and rooms.json. English and Persian interface.

Quick start

git clone https://github.com/shahmirdelfanazari/Microsoft-Exchange-2019-ON-Premises-Claude-MCP.git
cd Microsoft-Exchange-2019-ON-Premises-Claude-MCP
npm install
cp .env.example .env              # fill in your values
cp rooms.example.json rooms.json  # list your room mailboxes
npm start

Requirements: Node.js 20+, Exchange 2016/2019 with EWS, a service account with ApplicationImpersonation, an OIDC provider and a TLS reverse proxy. Then connect Claude Code with claude mcp add exchange --transport http https://your-server/mcp, or add a custom connector in claude.ai / Claude Desktop.
